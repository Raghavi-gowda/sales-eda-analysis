## 🎯 Project Overview
Performed end-to-end Exploratory Data Analysis on a retail
sales dataset using Python. Analysed customer behaviour,
revenue trends, product performance and branch-level metrics
to extract actionable business insights.

---

## 📁 Project Structure
sales-eda-analysis/
│
├── eda.ipynb          ← Main analysis notebook
├── sales.csv          ← Raw dataset
└── README.md

---

## 🔍 Analysis Performed

### 📅 Time Analysis
- Monthly revenue trend across 2024
- Quarterly revenue comparison
- Peak and low revenue months identified

### 🏷️ Product Analysis
- Revenue by product category
- Top 10 products by revenue
- Average order value by category

### 👥 Customer Analysis
- Member vs Normal customer comparison
- Gender × Category revenue heatmap
- Reward points analysis

### 🏢 Branch & City Analysis
- Revenue by branch
- City-wise performance comparison
- Correlation matrix of numeric variables

---

## 💡 Key Insights

| # | Insight | Action |
|---|---|---|
| 1 | Branch A handles 70% of revenue | Investigate Branch B capacity |
| 2 | Members spend more per order than Normal customers | Launch membership conversion campaign |
| 3 | Personal Care & Fruits = 45% of revenue | Prioritise stock for these categories |
| 4 | March is the lowest revenue month | Run promotions in February |
| 5 | Chicago leads all cities in revenue | Replicate Chicago strategy elsewhere |


2. Install dependencies:

3. Open the notebook:
```bash
jupyter notebook eda.ipynb
```
